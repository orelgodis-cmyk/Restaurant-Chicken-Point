# Chicken Point V6 — גרסה מצומצמת

במסך הראשי מופיעים רק שלושה ריבועים:

1. מעקב אוכל
2. מעקב גרין בול
3. המשימות שלי

אין טפסים פתוחים במסך הכניסה ואין גלילה ארוכה. כל נושא נפתח במסך נפרד.

## העלאה ל-GitHub Pages

העלה והחלף בפרויקט הקיים את ארבעת הקבצים:

- index.html
- app.js
- style.css
- manifest.json

לאחר מכן לחץ Commit changes. הנתונים הקיימים נשמרים, משום שהגרסה ממשיכה להשתמש באותו פרויקט Firebase ובאותם אוספי מידע.
